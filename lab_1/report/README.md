## Задача
Написать на `C++(C)` алгоритм, линейно вычисляющий произведение двух квадратных матриц одинкаовой размерности. Замерить время выполнения и другие показатели производительности написанного алгоритма. Результат работы алгоритма необходимо верефицировать при помощи сторонних библиотек на языке `Python`.

## Алгоритм
В однопоточном режиме вычисляется произведение матриц через тройной цикл. Матрицы хранятся в формате (row-major) и имеют тип `double`.

```cpp
const std::uint32_t n = a.get_rows();
const std::uint32_t m = a.get_columns();
const std::uint32_t p = b.get_columns();

matrix::Matrix result(n, p);
for (std::uint32_t i = 0; i < n; ++i)
{
    for (std::uint32_t k = 0; k < m; ++k)
    {
        const double a_ik = a(i, k);
        for (std::uint32_t j = 0; j < p; ++j)
        {
            result(i, j) += a_ik * b(k, j);
        }
    }
}
```

На каждой итерации фиксируется строка `i` матрицы `a` и столбец `k` матрицы `b`, затем внутренний цикл по `j` обновляет все элементы строки `i` матрицы `result`, используя одно значение `a[i][k]`. Такой порядок оптимизирует обращения к памяти: элементы `b` и `result` перебираются последовательно, а `a[i][k]` загружается один раз на `k`-ю итерацию.

### Предварительная оценка:
    `O(n*m*p)` - зависимость времени выполнения алгоритма от объёма входных данных, 
    `O(n*p)` - зависимость памяти затраченной на выполнение алгоритма от объёма входных данных.
